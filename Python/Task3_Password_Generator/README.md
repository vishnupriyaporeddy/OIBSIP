# Random Password Generator

## Project Description
The Random Password Generator is a Python application that creates secure random passwords based on the length and character types selected by the user.

## Features
- Allows users to choose the password length.
- Generates passwords using uppercase and lowercase letters.
- Provides an option to include numbers.
- Provides an option to include special symbols.
- Ensures selected character types are included in the generated password.
- Uses Python's `secrets` module for secure random generation.
- Validates user input.

## Technologies Used
- Python 3
- secrets module
- string module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python password_generator.py
```
