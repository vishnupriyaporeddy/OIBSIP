# BMI Calculator

## Project Description
The BMI Calculator is a simple Python application that calculates the Body Mass Index (BMI) based on the user's weight and height.

It displays the calculated BMI value and identifies the corresponding weight category.

## Features
- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI using the standard formula.
- Displays the BMI value.
- Classifies BMI into different weight categories.
- Validates user input to prevent invalid values.

## BMI Formula

BMI = Weight (kg) / Height (m)²

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 25 – 29.9 | Overweight |
| 30 and above | Obese |

## Technologies Used
- Python 3

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python bmi_calculator.py
```
